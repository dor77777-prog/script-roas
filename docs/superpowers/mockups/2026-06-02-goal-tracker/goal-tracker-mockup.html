בחרת טווח של 90 ימים. בחר חודש קלנדרי אחד (או הפריסט "החודש"), או דפדף עם ה-‹ › בכרטיס כדי לראות את היעד והביצוע מולו ולעבור אחורה בין חודשים.
מה זהה למקור: אותם 3 מדדים (נצבר/יעד/חיזוי), אותו פס סטטוס דק עם סימן "יעד יומי", אותה שורת תחתית (יום N מתוך M · נשארו · יעד יומי), אותו badge.
מה נוסף (פר-חודש): ① סטפר ‹ חודש › בכותרת + ✎ שעורך את יעד אותו חודש. ② חודש עבר שלם → ה-badge הופך ל"✓ עמד / ✗ לא עמד", העמודה השלישית הופכת ל"תוצאה מול יעד" (במקום חיזוי), והתחתית ל"ביצוע סופי". ③ חודש בלי יעד → היעד נגרר מהחודש האחרון (תווית "נגרר מ-X"). ④ עסקי בלבד (לא פר-חנות).
