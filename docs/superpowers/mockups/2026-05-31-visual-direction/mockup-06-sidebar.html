How you switch between them

STEP 1
Default load → collapsed
72px icon-rail. Active route gets violet accent + edge bar. Tooltip on hover shows label + keyboard shortcut.
STEP 2
Hover the sidebar
After 200ms hover anywhere on the sidebar, expand to 220px with labels. 200ms ease-out width transition. Click an item to navigate.
STEP 3
Pin open (optional)
Click a "pin" button in the sidebar footer → expanded state persists across pages. State saved in localStorage so it sticks across sessions.
STEP 4
Keyboard ⌘\\ to toggle
Power-user shortcut: ⌘\\ toggles between collapsed and pinned-expanded instantly. Same convention as VS Code / Cursor.
