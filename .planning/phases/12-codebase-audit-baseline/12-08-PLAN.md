    **Plan-agent task.** Procedure:

    1. **Grep all catch sites:**
       ```bash
       grep -rn --include='*.ts' --include='*.tsx' -E '^\s*\}\s*catch\s*\(' dashboard-web/src/
       ```
       Capture: `{file}:{line}` and the immediate following lines (4-6 lines of the catch body).

    2. **Classify each catch site:**
       - **intentional** if the catch body matches one of these patterns:
         - Comment `// soft-fail` / `// best-effort` / `// expected` within 3 lines
         - Re-throws via `throw err` / `throw new Error(...)` / `throw e`
         - Logs via `console.error` / `console.warn` AND continues with a sensible degraded path
         - Stores error via `notifyTokenFailure(...)`, `Sentry.captureException(...)`, `setError(...)`, or similar
         - Returns a typed error result (e.g. `return { ok: false, error: err.message }`)
       - **suspicious** if the catch body:
         - Is empty (`} catch (e) {}`)
         - Only references the error in a way that's discarded (e.g. `catch (e) { void e; }`)
         - Returns a default value without logging
         - Has no comment AND no re-throw AND no log AND no store

    3. **Caller chain via graphify** (best-effort):
       For each catch site's enclosing function, query the knowledge graph at `.planning/graphs/graph.json` to find which functions call it (up to depth 3). Use:
       ```bash
       node "$HOME/.claude/get-shit-done/bin/gsd-tools.cjs" graphify query "<enclosing-function-name>" --budget 1000
       ```
       Include the result inline as `caller_chain: [...]` (truncate to 5 callers max). If graphify returns nothing, set `caller_chain: []` — do not fail the sweep.

    4. **Cross-reference Phase 10 fixes:**
       Read `.planning/audit-2026-05-23-v3/AUDIT-phase9-snapshot.md` for HIGH-NEW-4 (Supabase `{error}` swallow in cron-live). Confirm that catch site is now **intentional** (re-throws). If it is — note the cross-ref in that entry's `notes`.

    5. **Write the output JSON:**
