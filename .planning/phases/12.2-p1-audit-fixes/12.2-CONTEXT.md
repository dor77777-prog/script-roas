## Specific Ideas

Each fix's `<action>` should map to its raw-returns `fix_sketch`:

- **ALG-01 (aiReport TikTok status):** Use `TIKTOK_ACTIVE_ENOUGH` set from `lib/platformConfig.ts` (already used by cronLive + postgresReaders symmetry per U-01). Replace allowlist `if (p === 'tiktok') return norm !== 'ADGROUP_STATUS_DELIVERY_OK'` with `if (p === 'tiktok') return !TIKTOK_ACTIVE_ENOUGH.has(norm)`.
- **ALG-02 (aiReport TikTok budget):** Add `ttSpend` to `totalSpendAll` accumulator. Probably 1-line fix.
- **ALG-07 (aiReport coverage clamp):** Remove `Math.min(1, ...)` clamp; surface raw ratio. May require new fixture to verify halo banner triggers.
- **INN-07 (cronLive Shopify-coupled gating):** Decouple — if `shopifyOk === false`, skip SHOPIFY-COLUMN writes but still run spend-only persist for the date.
- **INN-14 (DST):** Replace `start.getTime() + 24h` with Asia/Jerusalem calendar arithmetic via `Intl.DateTimeFormat('en-CA', { timeZone: 'Asia/Jerusalem' })`.
- **attributionAnalysis ALG-01:** Parameterize the 12+ "Meta" string literals to `${platform}` interpolation.
- **insights.ts ALG-01:** Track MTD COGS already-incurred separately; project only the REMAINING days using last-7 rate.
- **ordersAttribution.ts ALG-01:** Make `STORE_TAB_CONFIG` pagination dynamic (loop until last row) or raise cap to 1M.
- **ProductCentricView ALG-02:** Allocate stale-mapped revenue to the cohort's denominator (don't drop the campaign from Step-2).
- **ProductCentricView ALG-03:** Align JSDoc + impl — either keep `.filter(r => r.agg !== undefined)` AND update JSDoc, or remove filter AND update impl.
- **STA-46:** Replace inline `parseDate` with `lib/dateValidation.parseDate` (the WR-04-validated implementation).
- **STA-47:** Align filter semantics with `postgresReaders.fetchProductsFromPostgres`.
