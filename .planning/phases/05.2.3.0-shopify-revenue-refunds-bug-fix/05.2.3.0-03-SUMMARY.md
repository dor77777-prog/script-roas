## Algorithm Summary

### getShopifyRevenue (Task 2)

Before:
1. Builds an `orders.json?created_at_min/max` URL, paginates with 50-page safety cap, sums `current_total_price` for non-test non-voided orders into `total`.
2. Logs single-line summary.
3. Returns `total`.

After Plan 03:
1. Builds an `orders.json?created_at_min/max` URL, paginates with 50-page safety cap, sums `current_total_price` for non-test non-voided orders into `total`. (Unchanged.)
2. **New:** Calls `getShopifyRefundsForDay_(storeId, dateStr)` once, subtracts `refunds.storeRefundCad` from `total`. No clamping (D-D3).
3. **New:** Logs a 4-component summary: orders / gross-of-cross-day / cross-day-refunds + count / net.
4. Returns `total` (now net of cross-day refunds; may be negative).

### getShopifyProductSalesForDay (Task 3)

Before:
1. Builds an `orders.json?created_at_min/max&fields=...,line_items,refunds` URL, paginates.
2. For each order: builds a per-line-item refund map from `o.refunds[].refund_line_items[]` (intra-order, same-day), iterates `line_items[]`, computes `net = max(0, gross - lineDiscount - lineRefund)` and accumulates into `byProduct[key]`.
3. Logs single-line summary.
4. Transforms `byProduct` to array via `Object.values(byProduct).map(...).sort(...)`.
5. Returns array.

After Plan 03:
1. (Unchanged through step 2 above.)
2. (Unchanged — note the existing `Math.max(0, ...)` on the per-line computation IS preserved because it's the intra-line same-day refund deduction, where the line-level cap to 0 is correct: a single line can't go negative from its own order's same-day refunds. The cross-day deduction below DELIBERATELY DOES go negative because it applies aggregated across all of today's refund activity.)
3. (Existing 50-page warning unchanged.)
4. **New:** Calls `getShopifyRefundsForDay_(storeId, dateStr)` once. For each `pid` in `crossDayRefunds.byProduct`:
   - If `byProduct[pid]` exists (product had day-D sales): `byProduct[pid].netRevenueCad -= refundCad`.
   - Else (refund-only product): materializes `byProduct[pid] = { productId: pid, productTitle: '(refund-only)', units: 0, revenueCad: 0, netRevenueCad: -refundCad, orderIds: {} }`.
5. **New:** Logs a diagnostic showing total products with cross-day refunds and refund-only count.
6. Transforms `byProduct` to array unchanged — refund-only entries flow through the same `.map(p => ({ ... orders: Object.keys(p.orderIds).length }))` and emit with `units: 0, revenueCad: 0, orders: 0, netRevenueCad: -refundCad`.
7. Returns array.
