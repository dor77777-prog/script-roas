# Phase 05.2.3.0 Plan 08: Shopify Revenue Refunds — Gap-Closure Model Change Summary

## Algorithm Summary

### Before (PRE-gap-closure-08)
```
row[D] gross    = Σ current_total_price (orders.created_at=D, excl test/voided)
row[D] refunds  = Σ refund_line_items[].subtotal
                  (refunds.processed_at=D
                   AND order.created_at != D)   ← cross-day filter
row[D] net      = gross − refunds

per-product[pid][D].refundByLineId  = Σ rli.subtotal (no processed_at filter)  ← CR-02
per-product[pid][D].net             = max(0, gross − line_discount − line_refund)  ← CR-03 clamp
```

### After (POST-gap-closure-08)
```
row[D] gross    = Σ total_price (orders.created_at=D, excl test/voided)  ← total_price (immutable)
row[D] refunds  = Σ refund_line_items[].subtotal
                  (refunds.processed_at=D)                ← ONLY processed_at filter
row[D] net      = gross − refunds

per-product[pid][D].refundByLineId  = Σ rli.subtotal where processed_at == dateStr  ← CR-02 fixed
per-product[pid][D].net             = gross − line_discount − line_refund         ← CR-03 fixed (no clamp)
```

### Worked Example (uzoshop probe data)

Order 10803404276006: created `2026-05-02`, total_price=68.80, refund processed `2026-05-20` with refund_line_items[0].subtotal=68.80.

**Under the OLD algorithm:**
- 2026-05-02 row first write: gross_of_orders = +68.80, cross-day refunds = 0, net = +68.80.
- 2026-05-02 row re-write (20-day cleanup): `current_total_price` is now 0.00 → gross = 0.00, cross-day refunds = 0, net = 0.00. **Original row was silently overwritten.**
- 2026-05-20 row: cross-day deduction catches the refund → net = −68.80.
- Period sum: 0 + (−68.80) = **−68.80** (off by 68.80 — refund counted twice).

**Under the NEW algorithm:**
- 2026-05-02 row first write: gross = parseFloat(o.total_price) = +68.80, refunds = 0 (refund processed_at != 2026-05-02), net = +68.80.
- 2026-05-02 row re-write (20-day cleanup): gross = parseFloat(o.total_price) = +68.80 (immutable), refunds = 0, net = +68.80. **No change on re-write.**
- 2026-05-20 row: refunds includes refund_line_items[0].subtotal = 68.80 (processed_at == 2026-05-20), net = −68.80.
- Period sum: 68.80 + (−68.80) = **0.00** (correct — fully-refunded order has zero net revenue).

## Deviations from Plan

**Files modified:** `dashboard-web/src/lib/shopifyRevenueRefunds.ts` (Task 5 commit `0260cbf`).
