## Trust Boundaries

| Boundary | Description |
|----------|-------------|

| Writer SA → audit tab | The writer SA already has Editor on `dashboard-state` (06-01); we extend tab-level sharing to include `dashboard-state-audit`. (See 06-01 Task 2 step 3 — operator returns after this plan ships to add the audit tab to the writer SA's sheet-level protect list.) |
| Audit append failure → primary write | Audit must NEVER block or fail the primary write. Best-effort with try/catch + console.warn. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-03-01 | Repudiation | Cloud-state edits had no who/when/what record before this plan | mitigate | Every successful write appends a row with `[timestamp, key, old_value, new_value]`. 30-day retention via 06-04 prune trigger. |

| T-06-03-03 | Tampering | Audit row writes could be tampered by anyone with workbook Editor | mitigate | Tab-level sharing (06-01 step 3) restricts `dashboard-state-audit` to writer SA Editor + human operator Viewer (the human reads the audit; only the SA appends).
```typescript
// ============================================================================
// dashboard-state-audit — append-only forensic log of every state write.
// 4 columns: timestamp (ISO), key, old_value (truncated 500 chars), new_value.
// 30-day retention via Apps Script weekly trigger (06-04).
//
// Audit appends are best-effort: if Sheets API fails (transient network,
// quota), the primary write still succeeds and the user sees no error.
// console.warn surfaces the failure for ops; next write fills next row.
// ============================================================================

const AUDIT_MAX_VALUE_LEN = 500;

/**
 * JSON-stringify + truncate to AUDIT_MAX_VALUE_LEN. Suffix `...[trunc]` when
 * cut so anyone reading the audit knows the row is a partial-fidelity copy.
 * The full value lives in `dashboard-state` (not lost — audit is forensic
 * shorthand, not source of truth).
 */
function truncateAuditValue_(v: unknown): string {
  let s: string;
  try {
    s = typeof v === 'string' ? v : JSON.stringify(v);
  } catch {
    s = String(v);
  }
  if (s === undefined || s === null) return '';
  if (s.length > AUDIT_MAX_VALUE_LEN) {
    return s.slice(0, AUDIT_MAX_VALUE_LEN) + '...[trunc]';
  }
  return s;
}

/**
 * Ensures the `dashboard-state-audit` tab exists with the canonical header
 * row. Creates it (hidden:true to keep the UI tidy) if missing — mirrors the
 * pattern used by `ensureStateTab_` so the dashboard's first POST after
 * Phase 6 deploys self-bootstraps the audit tab.
 */
async function ensureAuditTab_(
  sheets: ReturnType<typeof google.sheets>,
  spreadsheetId: string,
): Promise<void> {
  try {
    await sheets.spreadsheets.values.get({
      spreadsheetId,
      range: `${AUDIT_TAB}!A1:D1`,
    });
    return; // tab exists
  } catch (err) {
    const msg = err instanceof Error ? err.message : String(err);
    if (!/Unable to parse range|not found/i.test(msg)) throw err;
  }
  await sheets.spreadsheets.batchUpdate({
    spreadsheetId,
    requestBody: {
      requests: [{ addSheet: { properties: { title: AUDIT_TAB, hidden: true } } }],
    },
  });
  await sheets.spreadsheets.values.update({
    spreadsheetId,
    range: `${AUDIT_TAB}!A1:D1`,
    valueInputOption: 'RAW',
    requestBody: { values: [['timestamp', 'key', 'old_value', 'new_value']] },
  });
}

/**
 * Appends one audit row to `dashboard-state-audit`. Best-effort: any failure
 * is logged via console.warn and swallowed, so a Sheets API hiccup never
 * blocks the primary write. The caller in `/api/dashboard-state/route.ts`
 * calls this via `void appendAuditRow(...)` so the promise rejection (if any)
 * is also non-blocking.
 *
 * Requires writer-mode credentials — see Phase 6 plan 01 for the
 * reader/writer split. The route handler must pass a sheets client created
 * from `getAuth('write')`.
 */
export async function appendAuditRow(
  sheets: ReturnType<typeof google.sheets>,
  spreadsheetId: string,
  key: string,
  oldValue: unknown,
  newValue: unknown,
): Promise<void> {
  try {
    await ensureAuditTab_(sheets, spreadsheetId);
    await sheets.spreadsheets.values.append({
      spreadsheetId,
      range: `${AUDIT_TAB}!A:D`,
      valueInputOption: 'RAW',
      insertDataOption: 'INSERT_ROWS',
      requestBody: {
        values: [
          [
            new Date().toISOString(),
            key,
            truncateAuditValue_(oldValue),
            truncateAuditValue_(newValue),
          ],
        ],
      },
    });
  } catch (err) {
    const msg = err instanceof Error ? err.message : String(err);
    // Best-effort: never throw. Ops see this in Vercel function logs.
    console.warn(`appendAuditRow failed for key=${key}: ${msg}`);
  }
}

export { AUDIT_TAB };
```

**עדכן את ה-POST handler** (שורות 69-101). החלף את הקיים בגרסה הבאה — הGET handler נשאר זהה לחלוטין:

```typescript
export async function POST(req: Request) {
  try {
    const body = (await req.json()) as { key?: unknown; value?: unknown };
    // Validate `key` against an explicit allowlist of dashboard-state keys.
    // (Defense in depth against prototype-pollution + type-system parity
    // with cloudSync.ts StateKey union. Unchanged from pre-Phase-6.)
    if (!isAllowedStateKey(body.key)) {
      return NextResponse.json({ error: 'unknown key' }, { status: 400 });
    }
    // Validate value size — see VALUE_MAX_BYTES above.
    const serialized = JSON.stringify(body.value ?? null);
    if (serialized.length > VALUE_MAX_BYTES) {
      return NextResponse.json({ error: 'value too large' }, { status: 413 });
    }

    // Primary write — captures the pre-write value as `oldValue` for the
    // audit log. If upsert throws, the user gets a 500 + no audit row is
    // written (correct: audit reflects only successful writes).
    const { oldValue } = await upsertDashboardStateKey(body.key, body.value ?? null);

    // Audit append — best-effort, fire-and-forget. The `void` makes the
    // promise rejection (if any) non-blocking on the 200 response. The
    // function itself never throws (try/catch inside), but `void` is
    // defensive in case future maintenance forgets that contract.
    //
    // We construct a NEW sheets client here rather than threading the one
    // from `upsertDashboardStateKey` through — the auth singleton inside
    // `getAuth` reuses tokens, so this is a cheap no-op call. Keeping the
    // upsert signature narrow (just `{ oldValue }`) is preferable to
    // leaking a sheets handle out of the lib layer.
    try {
      const auth = getAuth('write');
      const sheets = google.sheets({ version: 'v4', auth });
      const spreadsheetId = getSpreadsheetId();
      void appendAuditRow(sheets, spreadsheetId, body.key, oldValue, body.value ?? null);
    } catch (err) {
      // getAuth/getSpreadsheetId could throw if env vars are missing — but
      // upsertDashboardStateKey already succeeded, so the env vars MUST be
      // working. This catch is a safety net for ops visibility.
      const msg = err instanceof Error ? err.message : String(err);
      console.warn(`dashboard-state POST audit setup failed: ${msg}`);
    }

    return NextResponse.json({ ok: true });
  } catch (err) {
    const message = err instanceof Error ? err.message : String(err);
    console.error('dashboard-state POST failed:', message);
    return NextResponse.json({ error: userFacingError(message) }, { status: 500 });
  }
}
```

**הסברים נקודתיים על הבחירות:**

1. **למה לבנות sheets client חדש ב-route ולא להעביר מ-`upsertDashboardStateKey`?**
   - שמירה על interface narrow של ה-lib function. `upsertDashboardStateKey` מחזירה `{ oldValue }` ולא `{ oldValue, sheets, spreadsheetId }`. עקרון single responsibility: ה-lib יודעת לבצע upsert, ה-route יודעת לאסוף audit. אם נחזיר handle של sheets החוצה, נאלץ caller-ים אחרים לדעת על נוסף לזה ועל זה.
   - הexpensive חלק (`google.auth.GoogleAuth` instantiation) הוא singleton פנימית — קריאה שנייה ל-`getAuth('write')` באותה process חוזרת מהcache של ה-`googleapis` library.

2. **למה `void` לפני `appendAuditRow`?**
