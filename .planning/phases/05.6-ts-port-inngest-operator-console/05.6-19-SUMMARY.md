## Pattern Used

Verbatim from RESEARCH §Pattern 6.5 (lines 901-914). One concrete example, `/api/store-meta` before vs. after:

```typescript
// BEFORE
import { fetchStoreMeta } from '@/lib/sheets';
// ...
const rows = await fetchStoreMeta();

// AFTER
import { fetchStoreMeta } from '@/lib/sheets';
import { fetchStoreMetaFromPostgres } from '@/lib/postgresReaders';
import { readFrom } from '@/lib/featureFlags';
// ...
// D-E3 branch: postgres path dormant in 05.6; 05.7 flips READ_FROM=postgres.
// Both branches return StoreMetaRow[].
const rows = readFrom() === 'postgres'
  ? await fetchStoreMetaFromPostgres()
  : await fetchStoreMeta();
```

Special variant — `/api/data` uses `Promise.all` with `fetchTodayFx()`, so the conditional wraps the daily-data side and the `Promise.all` shape is preserved:

```typescript
const dailyPromise = readFrom() === 'postgres'
  ? fetchDailyDataFromPostgres({ range })
  : fetchDailyData({ range });
const [rows, fxIlsToCad] = await Promise.all([dailyPromise, fetchTodayFx()]);
```
