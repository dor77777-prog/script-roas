# Phase 05.2.1.1 Plan 01: Critical Algorithm Correctness Fixes

**Shipped the seven blocker fixes for Shopify day bounds, shared-tab writes, mapped-channel reconciliation, true-revenue allocation, and correlation semantics.**

## Performance
- **Duration:** 24min
- **Tasks:** 7
- **Files modified:** 7 (6 production files + 1 test file)

## Accomplishments
- Replaced the brittle organic whitelist with an inverted paid-exclusion predicate that includes `google-organic` and unknown legacy sources while excluding paid click IDs.
- Replaced Shopify hardcoded summer-offset day windows with `isoLocalMidnight_` timezone-aware bounds.
- Wrapped `writeProductSalesForDay_` in a script-wide `LockService` guard to serialize shared `products-daily` writes.
- Made Meta reconciliation symmetric with Google by summing all mapped Meta campaigns, not only the drawer campaign.
- Built campaign allocation spend from unfiltered store/date campaign rows so UI platform filters no longer change true revenue.
- Made the reconciliation narrative primary-channel-aware and limited the lag panel to Meta primary views.
- Moved Pearson helpers to `attributionAnalysis.ts`, returned `null` for no-variance/no-signal cases, rendered `-` for null correlations, and made lag selection positive-correlation-only.

## Files Created/Modified

- `Shopify.gs` now constructs Shopify order windows through `isoLocalMidnight_`.
- `SheetBuilder.gs` now serializes `products-daily` writes with `LockService`.

## Decisions Made
- Pearson `null` means "not computable"; UI displays `-` with a tooltip instead of treating no variance as real zero correlation.
- FIX-04 required test fixture updates because the old tests expected drawer-only Meta values even when no mapped Meta campaign rows were supplied.

## Deviations from Plan
- Direct `node -c Shopify.gs` and `node -c SheetBuilder.gs` fail in this environment before parsing because Node v25 rejects unknown `.gs` file extensions. Equivalent syntax checks passed via `node -c <(cat Shopify.gs)` and `node -c <(cat SheetBuilder.gs)`.

## Issues Encountered
- `buildReconciliation` tests initially failed after FIX-04 because fixtures did not include mapped Meta campaign rows. Resolved by updating fixtures to assert the new symmetric aggregation contract.
- Node's `.gs` path handling blocked the exact syntax-check command; resolved with process-substitution syntax checks against the same file contents.

## Flagged for Follow-up
