  <name>FIX-10: detectOutlierDays — median + MAD (robust)</name>
  <files>dashboard-web/src/lib/attributionAnalysis.ts</files>
  <behavior>
    Replace `detectOutlierDays`'s trailing-mean+stddev baseline with median + MAD (Median Absolute Deviation), the same robust approach already used in `insights.ts`. Prevents outlier cascading (an outlier day inflates the baseline, hiding the NEXT day's outlier).

    Standard formula:
    - Window = last N days (current N = 7, keep)
    - Median = middle value of sorted window
    - MAD = median of `|x_i - median|`
    - Outlier threshold: `|value - median| > k * MAD` where k = 3 (Tukey-style)
    - Edge case: if MAD = 0 (all values identical), use absolute difference + epsilon
  </behavior>
  <action>
    1. Open `dashboard-web/src/lib/attributionAnalysis.ts`. Find `function detectOutlierDays(...)`.
    2. Replace the mean+stddev logic with median+MAD. Reuse the median calculation from `insights.ts` if it's exported; otherwise inline a small one:
       ```typescript
       function median(arr: number[]): number {
         if (arr.length === 0) return 0;
         const sorted = [...arr].sort((a, b) => a - b);
         const m = sorted.length;
         return m % 2 === 0 ? (sorted[m/2 - 1] + sorted[m/2]) / 2 : sorted[Math.floor(m/2)];
       }
       function mad(arr: number[], med: number): number {
         if (arr.length === 0) return 0;
         return median(arr.map(x => Math.abs(x - med)));
       }
       ```
    3. Outlier detection per day:
       ```typescript
       const window = values.slice(Math.max(0, i - 7), i);  // last 7 days BEFORE current
       const med = median(window);
       const m = mad(window, med);
       const threshold = 3 * m;
       const isOutlier = m > 0
         ? Math.abs(values[i] - med) > threshold
         : Math.abs(values[i] - med) > 0.05 * med;  // fallback when MAD=0
       ```
    4. Existing tests in `detectOutlierDays.test.ts` will likely fail with the new logic — update them to match the new formula (median+MAD threshold). If you find tests that previously passed because of the cascading-outlier bug, that's actually a sign the new logic is correct.
  </action>
