<objective>
להפוך את עמודת ה-`Line Items (JSON)` (col N ב-`{store}-orders-attribution`) ל-opt-in. הקריאה היחידה שזקוקה לה היום היא `CampaignDrawer.productChannelBreakdown` — כל שאר הקריאות (CampaignsTable, table-level) יסתפקו בשורות "קלות" ללא העמודה הכבדה.

Output: ה-route מקבל `?lineItems=true|false` (ברירת מחדל false), ה-lib function משנה את ה-range read של Sheets API בהתאם, ו-2 קומפוננטות שינו את ה-SWR keys שלהן.

    הוסף parsing של `lineItems` query param. דוגמה (משתמש בתוצרי PLAN 02):

    ```typescript
    import { NextResponse } from 'next/server';
    import { fetchOrdersAttribution, type OrderAttributionRow } from '@/lib/ordersAttribution';
    import { parseRangeParams, RangeParamError } from '@/lib/dateRange';

    export const revalidate = 300;

    export type OrdersAttributionResponse = {
      rows: OrderAttributionRow[];
      lastUpdated: string;
      error?: string;
    };

    export async function GET(req: Request) {
      const searchParams = new URL(req.url).searchParams;
      let range;
      try {
        range = parseRangeParams(searchParams);
      } catch (e) {
        if (e instanceof RangeParamError) {
          return NextResponse.json({ error: e.message }, {
            status: 400,
            headers: { 'Cache-Control': 'no-store' },
          });
        }
        throw e;
      }
      // Default false — explicit opt-in via ?lineItems=true. Anything else
      // (missing param, 'false', '0', 'yes', etc.) → false to keep the
      // payload light. Only CampaignDrawer.productChannelBreakdown needs
      // lineItems today; all other callers benefit from the smaller body.
      const includeLineItems = searchParams.get('lineItems') === 'true';

      try {
        const rows = await fetchOrdersAttribution({ range, includeLineItems });
        return NextResponse.json(
          { rows, lastUpdated: new Date().toISOString() } satisfies OrdersAttributionResponse,
          { headers: { 'Cache-Control': 'public, s-maxage=300, stale-while-revalidate=900' } },
        );
      } catch (err) {
        const message = err instanceof Error ? err.message : String(err);
        console.error('orders-attribution fetch failed:', message);
        return NextResponse.json(
          { rows: [], lastUpdated: new Date().toISOString(), error: message } satisfies OrdersAttributionResponse,
          { status: 200 },
        );
      }
    }
    ```

    הערה: ה-cache-key של Vercel מבוסס על המלוא URL כולל query string, אז `?lineItems=true` ו-`?lineItems=false` יוצרים entries נפרדים — אין סיכון של "cached response עם line items מוחזר ללא line items".
